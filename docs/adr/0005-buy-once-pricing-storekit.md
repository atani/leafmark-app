# ADR-0005: 価格は無料 DL + 非消費型 IAP の買い切り(StoreKit 2)にする

- Status: Accepted
- Date: 2026-06-13

## Context

go-to-market.md で価格方針は「無料 DL + 買い切り IAP($9.99)のフリーミアム」と決定済み。
本 ADR では App Store 上の実装方式(課金商品の種類・StoreKit のバージョン・無料/有料の境界線)を確定する。

ターゲットは Marvin 難民 + サブスク疲れ層(顧客ペイン P8)。サブスク反発が来店動機そのものなので、
サブスクリプションは選択肢から外す。MVP の目標は Apple Developer Program ライセンス料($99)を
1か月以内に回収すること = 実質 12 本(net 約 $8.49/本、Small Business Program 15%)。

検討した課金形態:

1. **有料アプリ(paid up front)**: DL 時に $9.99
2. **無料 DL + 非消費型 IAP(non-consumable)**: 試用後にアンロック
3. サブスクリプション(auto-renewable)
4. 消費型 IAP

## Decision

**無料 DL + 単一の非消費型 IAP「Leafmark Pro」($9.99)** を StoreKit 2 で実装する。

- 課金商品: 非消費型 IAP 1 つ(`com.atani.inkwell.pro`)。サブスク・消費型は作らない
- フレームワーク: StoreKit 2(`Product`, `Transaction`, `Transaction.currentEntitlements`)。iOS 17+ 前提なので旧 StoreKit 1 は使わない
- 復元: `AppStore.sync()` による購入復元を設定画面に置く(Apple 審査要件)
- 価格帯: App Store 価格 Tier $9.99。Small Business Program(年間売上 $100万未満は手数料 15%)に登録
- レシート検証: StoreKit 2 の署名済み `Transaction`(JWS)をオンデバイス検証。サーバーは持たない(ADR-0002 のサーバーレス方針を踏襲)

### 無料/有料の境界線

| 機能 | 無料 | Leafmark Pro |
|---|---|---|
| EPUB インポート・レンダリング・ページめくり | ✅ | ✅ |
| レイアウト設定(フォント・行間・余白・2カラム・スクロール) | ✅ | ✅ |
| 全文検索・目次・辞書ルックアップ | ✅ | ✅ |
| ハイライト・注釈 | 1 冊あたり 3 件まで | 無制限 |
| Markdown エクスポート(Obsidian/Notion) | — | ✅ |
| 読書統計 | — | ✅ |

「読む」体験は永久無料にし、本を入れて描画品質・手触りを確かめてから買える試用導線にする。
課金の境界は **注釈ワークフロー(無制限ハイライト + エクスポート + 統計)** に置く。

## Rationale

- 非消費型 IAP は「サブスクではない買い切り」を App Store 上で最も素直に表現できる。有料アプリ(案1)は
  試用ができず、レンダリング品質を確認できないまま $9.99 を払わせることになり、Marvin 難民の
  「高機能リーダーになら金を払う」という動機(描画品質を見て納得して払う)と相性が悪い
- MarginNote(買い切り $10+)の成功が「注釈に金を払う市場がある」ことの証明。課金の境界を注釈に
  置くのは市場の支払い意思と一致する(go-to-market.md の前提)
- ハイライト 3 件の無料枠は「機能を体験させてから上限で買わせる」フリーミアムの定石。0 件だと
  価値を体験できず、無制限だと買う理由が消える
- StoreKit 2 はレシート検証をオンデバイスで完結でき、サーバーレス方針(ADR-0002)を崩さない
- 「Your highlights are yours.」の訴求(P2 × P8)は **エクスポート自由 = ロックインなし** の意味であり、
  買い切りで一度買えば自分のデータを自由に持ち出せることと矛盾しない

## Consequences

- 課金ロジック(`StoreManager`: 商品ロード・購入・`currentEntitlements` 監視・復元)と、Pro 機能の
  ゲーティング(ハイライト追加時の上限チェック、エクスポート/統計画面のロック)を実装する必要がある。
  → TODO の v1.0 リリース準備に「StoreKit 2 課金実装」として追加
- 無料枠の上限(3 件)は後から緩める方向の変更は容易だが、厳しくする変更は既存ユーザーの反感を買うため
  慎重に。初期値は緩めず 3 件で出す
- App Store Connect で IAP 商品の審査が別途必要(アプリ本体とは別レビュー)。スクリーンショット・
  審査用メモに「非消費型・買い切り・サブスクなし」を明記する
- 将来の大型機能(iCloud 同期など)は本 IAP に含めず、v2 の上位買い切りで回収する(go-to-market.md 2 節)
- 無料枠で「読む」が完結するため、Pro 未購入ユーザーのリテンションは課金転換率の母数として機能する
