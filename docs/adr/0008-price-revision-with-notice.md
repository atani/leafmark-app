# ADR-0008: Leafmark Pro を予告つきで $14.99 に改定し、Obsidian 向け書き出しを同時に強化します

- Status: Proposed
- Date: 2026-10-17

## Context

公開日（2026-06-27）から 2026-10-11 までの販売レポートの実績は次のとおりです。

| 項目 | 値 |
|---|---:|
| 初回 DL（`1F`） | 188 |
| Leafmark Pro 購入（`IA1`） | 8（10 月の CN 1 件は返金済みで差し引き 0） |
| DL から購入への比率 | 約 4.3% |
| 価格 | $9.99 / ¥1,500（手取り $8.49） |

購入 8 件はすべて英語圏と欧州（US・GB・DE・DK・ES）です。比率は `monetization.md` の「2〜5% は価格を据え置く」範囲にあり、律速は週 15 件前後の DL 数です。

月額・年額・買い切りの 3 プラン化も検討しました。ストアの説明文とキーワードは「Buy it once. No subscription」と「サブスクなし」を軸にしています。サブスクを足すと、ADR-0005 で集めると決めた層への訴求が崩れます。買い切りの競合 MapleRead SE は $8.99 の有料アプリです（2026-10-17 に US の Lookup API で確認）。Leafmark は無料で試してから買える点で差があります。

予告なしに値上げすると、未購入の利用者には理由が分かりません。現在の書き出しは見出しと引用だけの `.txt` で、Obsidian 向けを掲げる割に整形が足りません。

## Decision

1. サブスクは導入しません。商品は買い切りの `com.atani.inkwell.pro` 1 つのままにします。
2. 1.19 で Pro の書き出しを強化します。値上げの理由は「書き出しの機能が増えた」とします。
   - 拡張子を `.md` にします。
   - YAML front matter（`title` / `author` / `source: Leafmark` / `exported`）を付けます。
   - ハイライト色ごとに見出しで分けられる形式を選べるようにします。
   - 全冊のハイライトをまとめて書き出せるようにします。
   - 無料の 1 回目の書き出しも新形式にし、Pro で何が手に入るかを試せる状態を保ちます。
3. 1.19 のペイウォールに「2026-11-16 に価格を改定します。購入済みの方に追加料金はかかりません」と表示します。地域ごとに通貨が違うため、金額は書きません。日付を過ぎたら非表示にします。
4. 価格は 2026-11-16 に $14.99 へ改定します。基準地域は USA のままで、JP など他地域は自動換算に任せます。予約時に JP の換算額を確認して記録します。
5. 告知は次の 3 か所で行います。
   - ストアのプロモーションテキスト（審査なしで即日更新できます）
   - 1.19 の「新機能」欄
   - ペイウォール

## Consequences

- 購入済みの 8 人は非消費型のため影響を受けません。
- 予告期間には駆け込み購入の可能性があります。改定前後の購入件数は週次販売レポートで比較します。ただし件数が少ないため、価格の効果とは断定しません。
- 1.19 の審査が 11-16 までに通らない場合は、価格の改定日を後ろへずらします。ペイウォールの日付と食い違わないよう、価格改定の予約は 1.19 の配信を確認してから行います。
- 価格改定の予約は自動モードで止まる操作です。コマンドを `~/.claude/drafts/` に用意し、ユーザーが実行します。
- `monetization.md` の「100 購入で $14.99 を検証」は、本 ADR で前倒しします。理由は、購入数で判定できる規模になるまで時間がかかりすぎるためです。

## 見直し条件

- 改定後 8 週間の購入件数が改定前 8 週間の半分を下回り、同期間の初回 DL は減っていない場合に、価格を戻すかを検討します。
